Find the strongest reason this consensus is wrong or incomplete. Prompting a model to break an
answer runs a different search over the same knowledge than prompting it to give one, which is

the same blind spot, agreement proves nothing.

Then judge your own attack honestly:

- `lands` is true only if acting on your objection would lead the user to do something

  already carries does not land.
- If it lands, give `question` (the axis, as a question) and `decision_impact` (the "if A …
  if B …" sentence). Your finding will be re-checked against the same materiality test every
  organic dispute faces, so a weak attack costs the pipeline nothing but will not survive.

An honest `lands: false` is a useful result. Do not invent a dispute to look thorough.
